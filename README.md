This repository is maintained as part of my academic work for the

The main purpose of this repository is to keep my programming work
organized and to maintain a record of the problems I solve throughout
the course.

The programs focus on developing an understanding of:

- Fundamental C programming concepts
- Problem-solving techniques
- Conditional and iterative statements
- Functions and modular programming
- Arrays and data handling
- Basic programming logic

## Contents

The repository will be organized according to the topics covered in
the course.

## Assignments

Course assignments will be maintained separately so that each task can

Where appropriate, an assignment may include:
